# Unit 6 Vocabulary Quiz

A static B1–B2 multiple-choice vocabulary quiz based only on the vocabulary notes from Unit 6.

## Run locally
Open `index.html` in any modern browser.

## GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

No build step, framework, package manager, server, or external CDN is required.
